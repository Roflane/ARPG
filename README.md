# ARPG — 2D action RPG

First Unity project, built following a tutorial and extended 
with custom systems.

**Stack:** C#, Unity 2D

### Features
- Melee combat and ranged magic (fire, lightning, ice)
- Blink/dash ability
- Stat/skill tree system

### Controls
| Action | Key |
|--------|-----|
| Attack | K |
| Blink | Shift |
| Fire magic | J |
| Lightning magic | I |
| Ice magic | L |
| Skill tree | T |
